# Bulut Şekli Onay Kurulu

> Gökyüzünde bir şey gördüyseniz, o şey henüz resmi değildir.

Milattan Önce 412 yılında, bir çoban “koyun gibi duruyor” dediği anda devlet işe karıştı. O günden beri her bulut şekli, bu kurulun onayı olmadan kamuya açıklanamaz. Açıklanırsa yasal değildir. Yasal değilse bulut değildir. Bulut değilse yağmur yağmaz. Yağmur yağmazsa çay demlenmez. Çay demlenmezse toplantı olmaz. Toplantı olmazsa bu README yazılamaz.

Bu proje o toplantının yazılım karşılığıdır.

## Bu Yazılım Ne Yapar?

1. Siz bir bulut şekli söylersiniz. (Örn: “ejderha ama yorgun”)
2. Kurul üyelerinden rastgele biri dosyayı inceler.
3. Yüzde kırk iki ihtimalle red gelir. Çünkü kurul red yazmayı onay yazmaktan daha ciddi bulur.
4. Karar ekrana basılır. Evrak arşivlenmez çünkü arşiv henüz ihale aşamasındadır.

## Kurulum

```bash
python3 onay.py "tavşan gibi duran ama tavşan olmayan şey"
```

Argüman vermezseniz program size nazikçe sorar. Naziklik, yönetmeliğin 3. ekindedir.

## Bilimsel Dayanak

Yoktur. Ama yokluğun kendisi, kurulun 7 sayfalık gerekçe yazmasına yetmiştir.

## Sık Sorulan Sorular

**Bulut hareket ederse onay düşer mi?**  
Evet. Hareket, evrakta belirtilmeyen bir değişikliktir.

**Ejderha şekli onaylanır mı?**  
Nadiren. Ejderha, kurulun rakibidir.

**Bu siyasi midir?**  
Hayır. Bu tamamen meteorolojiktir.
